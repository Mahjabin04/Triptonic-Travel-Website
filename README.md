
# TripTonic

TripTonic is a responsive multi-page travel website focused on exploring destinations across Bangladesh.

The project allows users to browse different travel categories, read destination information and travel guides, select travel packages, and use a booking form to submit trip details.

## Features

* Responsive multi-page website
* Bangladesh destination pages
* Beaches, forests, hills, heritage sites, rivers, and northern destinations
* Travel package selection
* Booking form with validation
* Dynamic travel blog content
* Responsive navigation
* Destination-specific travel information
* Mobile-friendly design

## Technologies Used

* HTML5
* CSS3
* SCSS
* JavaScript
